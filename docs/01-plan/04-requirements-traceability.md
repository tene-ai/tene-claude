## 9. 추적성 유지 규칙

- 새 작업을 추가할 때 **반드시 요구사항 ID 를 명시**한다. 없으면 §8 에 근거를 적는다
- 요구사항이 변경되면 이 표를 먼저 갱신하고, 영향받는 작업을 표시한다
- 마일스톤 완료 시 해당 요구사항의 **검증 열을 실제로 실행**하고 결과를 기록한다
